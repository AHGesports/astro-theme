







# AutoFlow - AI Browser Automation Platform

## Product Overview

AutoFlow is an advanced AI browser automation platform designed for mass intelligent automation with the highest possible security and unique anti-bot mechanisms. Our goal is to create a comprehensive solution for users who need scalable, undetectable browser automation. we offer our solution as a B2C SaaS. 


## Core Features

When users open AutoFlow, they have access to the following main areas:

### 1. Profile Groups

- **Purpose**: Create and manage groups of AI agents organized by location or custom instructions
- **Functionality**: Users can create one or many profile groups to organize AI agents effectively
- **Use Case**: Group agents based on geographical location, business requirements, or specific automation tasks

### 2. Profiles (AI Agents)

**CRUD Operations**: Full Create, Read, Update, Delete functionality for profiles

Users can view and manage all created profiles (agents) in this section.

#### Profile Creation Flow

**A) Anti-Detection Provider Selection**
- **Current Options**: 
  - AdsPower
  - MoreLogin
  - GoLogin
  - Own browser (for tasks not requiring anti-detection)
- **Future Plans**: Launch AutoFlow's own anti-detect provider (potentially free)
- **Function**: Selected provider handles anti-detection and fingerprinting

**B) Profile Creation Modes**

1. **Fast Mode**
   - Creates basic agents without detailed data
   - Suitable for simple tasks that don't require extensive information

2. **AI Mode**
   - Creates agents with comprehensive real-world information:
     - Real location data
     - Authentic work history
     - Educational background
     - Additional real-world data
   - **Data Format**: All agent data stored in jsonResume format
   - **Mass Creation**: Can create multiple AI agents based on predefined profile groups
   - **Example**: Create 100 LinkedIn automation agents for Austria with authentic Austrian work and education histories

3. **Custom Mode**
   - Uses jsonResume format
   - Allows users to manually customize agent data
   - Full control over agent characteristics

#### Advanced Features
- **Custom MCPs**: Agents can access custom Model Context Protocols (MCPs) to gather data and execute user-defined functions

### 3. Actions

**CRUD Operations**: Create, Read, Update, Delete AI actions

- **Action Creation**: Simple prompt-based interface
- **Example**: "Go to LinkedIn and connect with 10 people who fit my business {business data}, then create personalized sales messages based on their profiles"
- **Workflow Integration**: Actions can be combined into workflows

### 4. Workflows

**CRUD Operations**: Create, Read, Update, Delete workflows

#### Workflow Creation Process
- **AI Nodes**: Add multiple AI nodes to create complex automation sequences
- **Node Configuration**: Each node can have:
  - Custom browser anti-detect configuration
  - Master prompt
  - Assigned action
- **Node Connectivity**: Nodes can be connected so one node's output becomes another's input
- **Scalability**: Create massive automated systems by chaining nodes and actions

#### Workflow Execution
- **Profile Selection**: Run workflows on one or multiple profiles
- **Parallel Execution**: Multiple profiles can run simultaneously
- **Real-time Monitoring**: Track status of each automation process
- **Result Visualization**: View GIF recordings of agent actions (clicks, typing, navigation)
- **Detailed Reporting**: Access complete action logs and AI agent responses

### 5. Scheduling

**CRUD Operations**: Create, Read, Update, Delete schedules

#### Scheduling Process
1. **Workflow Selection**: Choose workflow to schedule
2. **Profile Selection**: Select one or multiple profiles
3. **Time Configuration**: Set one or multiple execution times

**Purpose**: Enable future automation planning and mass scheduling capabilities

## Delivery Methods

### Cloud-Based Solution
- **Access**: Web-based platform
- **Execution**: All automation runs in the cloud
- **Benefits**: No local resource consumption
- **Target**:  All users who dont want to download exe and run workflows from different devices 

### Local Executable
- **Access**: Downloadable executable
- **Execution**: Runs on user's local machine
- **Benefits**: Cost reduction for users
- **Target**: Individual users and small teams
